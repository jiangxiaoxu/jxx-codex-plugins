# figma-generate-library

MCP resource: `skill://figma/figma-generate-library/SKILL.md`

Read when building or updating a Figma design system: tokens, variables, styles, components, component sets, variants, documentation, theming, or reconciliation with code. Also read when creating even a single production-quality component.

Required before tool call: read with `figma-use` before Figma writes. For component creation, treat this route as required because component quality depends on variable foundations, variants, and token bindings.

Local plugin reference: read only the phase-specific references and helper scripts selected by the MCP skill, such as discovery, token creation, component creation, naming conventions, documentation, Code Connect setup, or error recovery.
