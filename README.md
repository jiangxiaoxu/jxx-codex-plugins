# jxx-codex-plugins

Codex plugin marketplace repository.

The first bundled plugin is `node-repl`. Its Windows runtime is vendored from the Microsoft Store Codex x64 MSIX as `plugins/node-repl/runtime/bin/node_repl.exe`.

Included plugins:

- `node-repl`: local Node REPL MCP server wrapper.
- `rg`: Node REPL helper for structured ripgrep search sessions.
- `chatgpt-research-prompt`: copy-ready research prompt generator for ChatGPT Pro web search.
